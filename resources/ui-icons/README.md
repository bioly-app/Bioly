# Interface icons

Icons of the Bioly interface: backend (navigation, buttons, editor, forms) and the arrows on the link buttons
of the public page. They are not part of the icon picker.
Use them in Twig with `{{ ui_icon('name') }}` or `{{ ui_icon('name', 'css-class') }}`.
